# 样例视频首次完整推理记录

日期：2026-09-17。运行环境见 [server-environment.md](server-environment.md)。此记录针对用户提供的 `data/example/xzg_314700.mp4`，原视频、模型权重和运行产物均不随此文档发布。

## 命令与产物

```bash
PYTHONPATH=src .venv/bin/python -m video_demo.cli analyze \
  data/example/xzg_314700.mp4 \
  --output runs/sample-full \
  --model models/Qwen3-VL-8B-Instruct
```

服务器产物位于 `~/video-demo/runs/sample-full/`：`result.json`、`summary.md`、`manifest.json`、`run.log`、`evidence/`。此目录被 Git 忽略。模型为本地 `Qwen3-VL-8B-Instruct`，每 20 秒一个片段，每片段均匀抽取 4 帧；没有调用云推理 API。

## 人工抽查与限制

- 第 4 段（60–80 秒）写了“部分积木已倒塌”。抽看 62.5、67.5、72.5、77.5 秒画面，未见明确倒塌瞬间；应将该说法视为**未确认**，不能当作有证据的任务结果。
- 多数片段重复概括“搭建积木”，未拆出每个人各自完成的动作，也没有判断任务是否完成。第 8、9 段使用“城堡”“围墙”等词，属于对积木形状的解释，仍需人工复核。
- 输出的 `review_required=true` 与警告“人物关联尚未启用”是必要的。当前只验证了视频描述链路和时间/文件结构，尚未满足跨时段识别同一人物的核心目标。
- 后续需接入人体检测、轨迹及外观重识别，用该视频中反复出镜的人测试匿名 ID；同时对“倒塌”“完成”等结果性描述增加证据约束。
