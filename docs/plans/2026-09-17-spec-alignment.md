# MVP 技术规格对齐实施计划

**目标：** 将现有固定切段描述闭环扩展为 `docs/mvp-technical-spec.md` 中的离线镜头、人物、语音、结构化事件与证据链，并在 L20 上跑完整样例。

**架构：** 各模块只产出带毫秒时间戳的中间数据；聚合器负责人物映射、证据校验、去重和摘要。模型之间不得互相推断身份。下载权重只发生在准备阶段，运行阶段读取本地路径。

**取舍：** RT-DETR/BoT-SORT 使用 Ultralytics 接口逐镜头跟踪；FastReID 外观向量由独立适配器产生，阈值必须显式配置并标记未校准。没有可信外观向量时不跨镜头自动合并。语音不自动归属到人物。对固定样例只报告工程闭环，效果指标留待独立标注集。

## 阶段 1：输入和切段

- 测试：镜头边界覆盖、长镜头 2 秒重叠、帧 ID/时间戳、无音轨与坏文件。
- 实现：PySceneDetect 内容切分；15–30 秒片段；约 1 FPS 的事件帧与更高频率的跟踪帧；FFmpeg 音轨。
- 验证：纯逻辑测试、合成有切换的视频。

## 阶段 2：人物链路

- 测试：轨迹不跨镜头重用局部 ID；重叠人物不合并；无向量/中间分数列待复核；人物证据必须在框内对应帧。
- 实现：RT-DETR 人体检测接 BoT-SORT；代表框裁剪经 FastReID 取向量；现有关联器输出 P1/P2、候选与 `tracks.json`。
- 验证：合成数据、服务器短片推理、完整样例的轨迹/证据抽检。

## 阶段 3：语音、事件与报告

- 测试：无语音无 transcript；语音时间戳；候选 JSON 格式错误/越界/虚构人物降级；无结果证据不能输出已完成；摘要只用验证事件。
- 实现：faster-whisper 本地转写；Qwen3-VL 结构化候选；事件证据核验、去重、任务配置与退出码；manifest 记录权重哈希/版本和运行参数。
- 验证：全量单元测试、完整样例离线运行，逐项核对产物和时间范围。

## 阶段 4：验收报告

- 记录真实命令、模型路径与哈希、耗时/显存/产物大小、已知错误。
- 对照规格工程验收逐项报告；至少 20 段授权标注视频和阈值校准属于效果验收，当前样例无法代替。
